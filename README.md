# 🐍 Python Question Practice

A beginner-friendly **Python Question Practice** project containing 30 programming questions to practice fundamental Python concepts.

The project provides an interactive menu-driven dashboard where users can select a question, enter the required input, and see the output.

---

## 📌 About the Project

This project was created to practice and strengthen basic Python programming concepts through small problem-solving exercises.

The questions cover:

- Numbers
- Strings
- Loops
- Conditional statements
- Functions
- String methods
- Slicing
- Nested loops
- Pattern printing
- Basic problem solving

## 📂 Project Structure

```text
Python-Question-Practice/
│
├── app.py
├── config.py
├── dashboard.py
└── README.md
```

### `app.py`

The main entry point of the application. It imports and calls the `dashboard()` function to start the program.

### `config.py`

Contains the individual Python practice functions.

Examples include:

```text
even_odd()
check_number()
find_largest()
find_largest_three()
sum_natural()
multiplication_table()
factorial()
count_digits()
reverse_number()
check_prime()
```

It also contains string-related problems such as character counting, vowel counting, palindrome checking, word counting, removing spaces, finding the longest word, and more.

### `dashboard.py`

Contains the interactive menu and connects each menu option with its corresponding function. It uses `match-case` to execute the selected question.

## 📚 Learning Objective

The main objective of this project is to improve **Python fundamentals and logical problem-solving skills** by implementing common programming questions without relying heavily on advanced libraries or techniques.

Some problems intentionally avoid built-in functions so that the underlying logic can be practiced. For example, character counting is implemented using a loop rather than `len()`, and word counting is implemented without using `split()`.
